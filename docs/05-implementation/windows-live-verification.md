# Ручная проверка на Windows с живой ACC (закрытие Phase 1)

Разовая проверка на Windows-машине с установленной ACC. Цель — подтвердить три вещи,
которые невозможно проверить тестами без игры:

1. сегменты записи появляются и ротируются;
2. частота кадров ≈ 333 Hz;
3. запись переживает рестарт игры.

Займёт ~15 минут. Снятие SHM-дампов (отдельная задача) описано в
`tests/SimCoach.Adapters.ACC.Tests/Fixtures/README.md` — удобно сделать в той же сессии.

## Подготовка

Самый быстрый путь — **не собирать вручную**: возьми готовый self-contained `SimCoach.App.exe`
из CI. Открой Actions → workflow **Publish (Windows exe)** → нужный запуск → артефакт
`SimCoach-win-x64` (или запусти его вручную через «Run workflow»). Внутри `SimCoach.App.exe` +
`appsettings.json`; .NET ставить не нужно — рантайм вшит. Распакуй, при необходимости поправь
`appsettings.json`, запусти exe. Дальше сразу к [Шагу 1](#шаг-1--запуск-до-игры-reconnect-ожидание).

Если всё же собираешь из исходников:

1. Установи .NET 9 SDK (или новее — `global.json` сам прыгнет на мажор выше).
2. Склонируй репозиторий, из его корня:

```powershell
dotnet build SimCoach.sln
```

Сборка должна пройти без ошибок. Если установлен только рантайм 10+, для тестов нужен
префикс `DOTNET_ROLL_FORWARD=LatestMajor` (build/run не требуют).

## Шаг 1 — запуск ДО игры (reconnect-ожидание)

```powershell
dotnet run --project src/SimCoach.App
```

Конфиг по умолчанию уже правильный (`Telemetry:Source = "acc"`). Ожидаемо:

- приложение запустилось и **молчит** (никакого спама в лог раз в секунду — попытки
  подключения тихие);
- ошибок нет.

Логи: консоль + `%LOCALAPPDATA%/SimCoach/logs/simcoach-<дата>.log`.

## Шаг 2 — подключение и запись

Не закрывая приложение, запусти ACC → любая машина/трасса → **практика** → выезд на трек.

ВАЖНО: страницы shared memory создаются при входе в сессию, не на старте игры.

Ожидаемо в логе:

```
[INF] Connected to ACC shared memory
[INF] Recording telemetry to %LOCALAPPDATA%\SimCoach\recordings\<yyyyMMdd-HHmmss-fff>\segment-0000.mcap
```

## Шаг 3 — ротация и частота (≈333 Hz)

Проедь 2–3 минуты. Каждые 60 секунд в логе:

```
[INF] Segment 0 finished: 23990 frames in 60.0 s (~400 Hz)
[INF] Recording telemetry to ...\segment-0001.mcap
```

Критерии:

- **частота в строке `Segment N finished` — ~400 Hz** (реально измерено на железе; «333» в доке
  Kunos — номинал, фактический темп обновления страницы выше). Существенно ниже (например ~64 Hz)
  = риск гранулярности Windows-таймера в поллере; лечится подъёмом разрешения таймера
  (`WinTimerResolution`, см. `AccReaderOptions.PollInterval`) — зафиксируй число;
- сегменты нумеруются подряд (`segment-0000`, `0001`, ...), каждый ~60 секунд;
- предупреждений `Slow telemetry consumers dropped...` нет (или единичные).

Пауза игры (Esc): кадры замирают (packetId не растёт — дедупликация), сегмент просто
дольше наполняется. Это норма.

## Шаг 4 — рестарт игры

1. Полностью закрой ACC (не выходя из приложения). Лог замолчит — **это ожидаемо**:
   закрытие игры не детектится как disconnect (наш handle держит секцию живой),
   кадры просто перестают приходить.
2. Запусти ACC снова, зайди в сессию, выезжай на трек.
3. Ожидаемо: кадры пошли снова (ротации сегментов продолжаются, частота в норме) —
   **без рестарта приложения**.

## Шаг 5 — финал

Останови приложение (Ctrl+C). Ожидаемо в логе:

```
[INF] Segment N finished: ... frames ...
[INF] Recorder stopped: N segment(s) in ...
[INF] Telemetry ingest stopped for sim acc; 0 frames dropped in total
```

Проверь запись (опционально, нужен [mcap CLI](https://mcap.dev/guides/cli)):

```powershell
mcap doctor "$env:LOCALAPPDATA\SimCoach\recordings\<sessionId>\segment-0000.mcap"
```

Ожидаемо: exit 0; строка `Header.profile field "x-simcoach" is not a well-known profile` —
информационная, это норма.

## Чеклист результата

- [ ] До игры: тихое ожидание, без ошибок
- [ ] Вход в сессию: `Connected` + `Recording telemetry to ...segment-0000.mcap`
- [ ] Частота из `Segment N finished`: ____ Hz (цель 300–333)
- [ ] Ротация каждые ~60 c, номера подряд
- [ ] Дропов нет (или единичные)
- [ ] Рестарт ACC: кадры возобновились без рестарта приложения
- [ ] `mcap doctor`: exit 0
- [ ] Бонус: одна записанная сессия сохранена — пригодится как fixture для Phase 2

## Если что-то не так

Сохрани и приложи: полный лог-файл из `%LOCALAPPDATA%/SimCoach/logs/`, версию ACC,
замеренную частоту. Частота ~64 Hz лечится настройкой поллера — известный план B7,
данные с реальной машины нужны, чтобы выбрать фикс (timeBeginPeriod / SpinWait).
