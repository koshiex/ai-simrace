# Action Registry

Bounded set of coaching actions the LLM may select. The LLM does NOT generate free-form prose for in-corner / sector / lap cadences — it selects an `action_id` and produces a single short Russian phrase.

This file is the canonical list. The MVP set is small (~20 actions). Phase 2 adds race-craft actions.

---

## Schema

Each action:

```yaml
id: brake_later_by_meters
when:
  - corner.brake_point_diff_m < -2.0  # braked too early
  - !corner.off_track
params:
  - corner: string
  - meters: float  # how much later
phrase_template_ru: "В {corner} тормози позже на {meters:0} метров."
priority: high  # high | medium | low
cadence: corner  # corner | sector | lap
```

`when` defines when this action is *valid* given the Gold artifact. The LLM may not pick an action whose `when` clauses fail.

`phrase_template_ru` is the fallback used when the LLM either fails schema or returns an out-of-spec phrase. The LLM is otherwise free to generate its own short phrase that respects the word limit.

## MVP Actions (session cadence — post-session, longer-form)

Post-session uses free-form text up to 200 words, generated by `deepseek/deepseek-chat-v3.2`. Constrained by a JSON schema that enforces three sections:
- `top_losses` — array of {corner, ms, why}
- `top_priority` — single most impactful fix for next session
- `setup_hint` — optional one-line understeer/oversteer flag

## How the LLM sees this

The PromptBuilder injects only the *valid* subset (where `when` is satisfied by the current Gold artifact). The LLM picks one `action_id` from that subset and generates a phrase. If it returns an `action_id` not in the valid subset, the schema validation fails and we fall back to template.
